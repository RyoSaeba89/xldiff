XLDiff
Comparateur de fichiers Excel

Que recherchez-vous ?

XLDiff analyse deux ou trois fichiers Excel directement dans votre navigateur. Commencez par choisir le type d'analyse.

Vos deux fichiers ont-ils les mêmes colonnes ?
Oui — comparatif simple
Deux fichiers issus du même export Excel (mêmes colonnes). La comparaison est entièrement automatique.
  • Déposez les deux fichiers
  • Colonnes communes détectées automatiquement
  • Comparaison sur toutes les colonnes
Commencer →
Non — comparatif avancé
Deux ou trois fichiers différents. Associez les colonnes qui identifient une ligne, et vérifiez au besoin le contenu d'autres colonnes (l'adresse, par exemple).
  • Déposez deux fichiers (un troisième au besoin)
  • Associez les colonnes A ↔ B ↔ C
  • Lignes absentes et écarts de contenu
Commencer →
Vos deux fichiers ont-ils les mêmes colonnes ?
Oui — doublons simple
Deux fichiers issus du même export Excel (mêmes colonnes). La recherche est entièrement automatique.
  • Déposez les deux fichiers
  • Colonnes communes détectées automatiquement
  • Doublons si toutes les colonnes sont identiques
Commencer →
Non — doublons avancé
Deux ou trois fichiers différents. Associez les colonnes à comparer : deux lignes sont en double si ces colonnes sont identiques.
  • Déposez deux fichiers (un troisième au besoin)
  • Associez les colonnes A ↔ B ↔ C
  • Doublons sur les colonnes choisies
Commencer →
100 % local — vos fichiers sont traités dans votre navigateur, aucune donnée n'est envoyée sur le réseau.
