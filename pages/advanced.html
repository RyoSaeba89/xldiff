Pour comparer trois fichiers
1. Choix des feuilles
Un des fichiers contient plusieurs feuilles (onglets Excel) : choisissez la feuille à comparer pour chaque fichier.
Colonnes de rapprochement
Associez chaque colonne du fichier A à la colonne correspondante des autres fichiers. Ces colonnes servent à retrouver la même ligne dans chaque fichier (par exemple le nom et la date de naissance) : une ligne sans équivalent est signalée comme différence. Les colonnes de même nom sont pré-associées.
Colonnes à comparer (facultatif)
Une fois la ligne retrouvée dans chaque fichier, vérifiez le contenu de ces colonnes (par exemple l'adresse) : les lignes retrouvées dont une de ces colonnes diffère sont listées à part, dans l'onglet « Retrouvées mais différentes ». Sans aucune colonne ici, seule la présence des lignes est vérifiée. Les majuscules et les espaces en trop sont ignorés.
Une ligne présente dans tous les fichiers n'est pas signalée comme différence, même si elle se répète plus de fois dans un fichier que dans un autre (par exemple 3 fois dans le fichier A et 1 fois dans le fichier B). Seules les lignes absentes d'un fichier sont signalées.
